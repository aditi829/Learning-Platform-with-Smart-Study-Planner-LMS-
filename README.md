# 📚 Learning Platform with Smart Study Planner (LMS)

An intelligent **Learning Management System (LMS)** designed to provide students with an interactive learning experience while helping them stay organized through a **Smart Study Planner**. The platform combines learning resources, progress tracking, quizzes, and study scheduling into a single web application.

---

## 🚀 Features

### 👨‍🎓 Student Module
- User Registration & Login
- Browse learning materials
- Access video lectures and study resources
- Track learning progress
- Smart Study Planner
- Personalized study schedule
- Quiz & assessment system
- Responsive dashboard

### 👨‍💼 Admin Module
- Secure Admin Login
- Manage courses
- Upload learning materials
- Manage users
- Monitor student activities
- Update educational content

## ⚡ Installation

### 1. Clone the repository

```bash
git clone https://github.com/aditi829/Learning-Platform-with-Smart-Study-Planner-LMS-.git
```

### 2. Navigate into the project

```bash
cd Learning-Platform-with-Smart-Study-Planner-LMS-
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

**Windows**

```bash
venv\Scripts\activate
```

**Linux / macOS**

```bash
source venv/bin/activate
```

### 5. Install dependencies





### 7. Run the application

```bash
python app.py
```

Open your browser and visit:

```
http://localhost:5000
```
